# Гуль — умный голосовой ассистент на Acer Aspire R3700

> «Алиса, но умнее, бесплатно и без ограничений» — это реально, если правильно
> разделить труд: **неттоп слышит и говорит, а думает бесплатное облако.**

Гуль — открытый голосовой ассистент для слабого железа. Он понимает русскую речь
офлайн, мгновенно выполняет бытовые команды, а на сложные вопросы отвечает через
бесплатные нейросети (Groq, GigaChat, Cloudflare) с автоматическим переключением.
Ни подписки, ни рекламы, ни «извините, я не могу обсуждать эту тему».

---

## Вердикт: затея реальная, но не «в лоб»

Acer Aspire R3700 — это Intel Atom **D525** (2 ядра, 1.8 ГГц, 2010 год),
**максимум 4 ГБ DDR3**, без SSE4/AVX (только SSE2/SSE3/SSSE3).
Запустить на нём современную умную LLM локально нельзя: большая модель выдаст
1–3 токена в секунду, а многие бинарники (torch, onnxruntime, ctranslate2)
просто упадут с `Illegal instruction`. Это не вопрос настройки — это физика.

Зато D525 отлично справляется с тем, что нужно голосовому ассистенту:

| Задача | Где выполняется | Задержка |
|---|---|---|
| Слово активации «Привет, Гуль» | локально, Vosk | 0.2–0.5 с |
| Распознавание команды | локально, Vosk | 0.2–0.6 с |
| Время, таймеры, будильники, заметки, память, калькулятор | локально, Python | 1–50 мс |
| Погода, новости, курсы, Википедия | бесплатные API, кэш | 0.3–1.5 с |
| Свободный разговор, советы, объяснения | Groq / GigaChat / Cloudflare | 0.2–0.6 с до первого токена (Groq через релей) |
| Синтез речи | Edge TTS, Piper, RHVoice или espeak | 0.1–0.8 с на первую фразу |

**Итог:** бытовые команды — **0.5–1.5 секунды**, умные ответы — **1.5–3.5 секунды**
до первого звука. Требование «не больше 5 секунд» выполняется с запасом.
Всё бесплатно: GigaChat даёт физлицам **365 млн токенов в год**, Cloudflare —
**10 000 нейронов в день**, погода/Википедия/RSS/курсы ЦБ — без ключей.

## Как устроено

```
                 ┌──────────────────────── Acer Aspire R3700 ───────────────────────┐
 Микрофон ──────▶│ arecord → VAD → Vosk wake-word «Привет, Гуль»                      │
                 │                        │                                          │
                 │                        ▼                                          │
                 │              Vosk STT (офлайн) ──▶ диспетчер скиллов             │
                 │                                        │                          │
                 │              ┌─────────────────────────┴───────────────┐          │
                 │              ▼                                         ▼          │
                 │        быстрый скилл                            LLM-роутер         │
                 │   (время, таймер, заметки, калькулятор)   Groq → GigaChat →       │
                 │              │                              Cloudflare → mock    │
                 │              └─────────────────────┬───────────────────┘          │
                 │                                    ▼                              │
                 │                       TTS: Edge → Piper → RHVoice → espeak        │
                 │                                    │                              │
                 └────────────────────────────────────┼──────────────────────────────┘
                                                      ▼
                                                 Колонка
```

Ключевая идея: **локально — всё, что можно сделать за миллисекунды; в облако —
только текст вопроса, когда нужен настоящий интеллект.** Это одновременно
быстрее, дешевле и приватнее, чем гонять звук в облако целиком.

## Что умеет

### Быстрые локальные команды (работают без интернета)

- ⏰ «Который час», «какое сегодня число», день недели
- ⏱ Таймеры: «поставь таймер на 10 минут»
- ⏰ Будильники: «будильник на 7:30», «каждый день»
- 📝 Напоминания: «напомни через час позвонить маме»
- 🧮 Калькулятор: «15 процентов от 2000», «2 плюс 2 умножить на 3»
- 📏 Единицы: «сколько метров в 5 километрах»
- 🛒 Список покупок и заметки: «добавь в список покупок молоко»
- 🧠 Память: «запомни, что я люблю кофе без сахара» — и ассистент учитывает это в разговоре
- 🎵 Музыка и радио через mpv: «включи радио Европа Плюс», «громче», «пауза», «следующий»
- 💡 Умный дом по MQTT: «включи свет на кухне» (настраивается в `config.yaml`)

### Через бесплатные API

- 🌤 Погода сейчас и на 2 дня, в любом городе (Open-Meteo, без ключа)
- 📰 Новости из RSS, включая тематические («новости спорта»)
- 💵 Официальные курсы ЦБ РФ и перевод сумм
- 📚 Википедия: «кто такой Юрий Гагарин», «что такое чёрная дыра»
- 🌐 Перевод на десятки языков
- 💬 Свободный разговор на любые темы, объяснения, советы, идеи, шутки, учеба

### Голос и интерфейс

- Слово активации на выбор: «Привет, Гуль», «Слушай, Гуль», «Гуля»
- Перебивание словом «стоп» во время ответа
- Веб-интерфейс с живыми метриками задержки, статусом мозгов и списком умений
- Потоковая озвучка: ассистент начинает говорить, пока нейросеть ещё дописывает ответ
- Автопереключение мозгов при сбое, лимите токенов или блокировке по региону
- Четыре TTS-движка с фолбэком: Edge → Piper → RHVoice → espeak

слышит ответ, а не ошибку.

(5 минут, бесплатно, VPN не нужен) и прописать в `.env` два значения.
Ключ Groq при этом остаётся в секретах Worker. Пошагово: [docs/GROQ.md](docs/GROQ.md).

## Быстрый старт

### 1. Система

Рекомендую **Debian 12/13 без графики** и проводной интернет. Установка занимает
~15 минут, потребление RAM — меньше 1 ГБ. Пошаговая инструкция для R3700 —
в [docs/HARDWARE.md](docs/HARDWARE.md).

```bash
sudo apt update && sudo apt install -y git
git clone https://github.com/ToshakGulina/GulAssistant.git
cd GulAssistant
bash scripts/setup_debian.sh
bash scripts/quickstart.sh          # ключи, модель и проверка мозгов
```

Скрипт поставит Python, ALSA, ffmpeg, mpv, espeak-ng, создаст venv, скачает
модель Vosk (~45 МБ), подготовит конфиг и systemd-службу.

### 2. Ключи

```bash
nano .env
```

Основной мозг — Groq через свой релей (быстрее всех). Если релея нет,
работает GigaChat — бесплатно и из РФ без VPN:

```
GIGACHAT_CLIENT_ID=...
GIGACHAT_CLIENT_SECRET=...
```

```dotenv
# Быстрый путь: Groq через свой Cloudflare-релей (docs/GROQ.md)
GROQ_RELAY_URL=https://gul-groq-relay.xxx.workers.dev/openai/v1
GROQ_RELAY_TOKEN=ваш_пароль_релея

# Или без релея: GigaChat, бесплатно для физлиц
GIGACHAT_CLIENT_ID=...
GIGACHAT_CLIENT_SECRET=...
```

Всё это можно ввести интерактивно: `bash scripts/quickstart.sh`.
Ключи GigaChat выдаются в [кабинете GigaChat API](https://developers.sber.ru/portal/products/gigachat-api).
Если ключей нет вообще — ассистент запустится в демо-режиме, а все быстрые
команды будут работать.

### 3. Проверка и запуск

```bash
.venv/bin/python run.py --check         # что настроено, что нет
.venv/bin/python run.py --doctor        # полная диагностика: звук, Vosk, TTS, мозг
.venv/bin/python run.py --mic-test 4    # записать микрофон и оценить уровень
.venv/bin/python run.py --speaker-test  # услышать ответ настоящим TTS
.venv/bin/python run.py --list-devices  # микрофон и колонка
.venv/bin/python run.py --bench         # реальные задержки на вашем железе
.venv/bin/python run.py                 # голос + веб на :8787
```

Откройте `http://IP-НЕТТОПА:8787` с телефона или компьютера — там чат, метрики
и статус провайдеров.

Служба автозапуска:

```bash
sudo systemctl start gul
journalctl -u gul -f
```

## Отладка на мощном ПК, работа на Acer

Если неттоп ещё не готов или отлаживать на нём неудобно — не надо ничего
упрощать. Поставьте **тот же Debian** на отдельный диск основного ПК и гоняйте
ту же сборку: тот же Vosk, тот же ALSA, тот же TTS, тот же код. Отличие только
в скорости железа, а рабочий стол и браузер нужны лишь для удобства.

```bash
bash scripts/install_testbox.sh        # Debian + XFCE + Firefox + весь стек
bash scripts/emulate_acer.sh .venv/bin/python run.py --web   # ~2 ядра, 20% CPU
bash scripts/deploy_to_acer.sh --host gul@acer.local --config --env
```

Полная инструкция, включая установку Debian на второй диск без риска для
Windows: [docs/DEVBOX.md](docs/DEVBOX.md).

## Задержка: из чего складывается и как уложиться в 5 секунд

| Этап | Типично | Что влияет |
|---|---|---|
| Wake-word | 0.2–0.5 с | Vosk small, грамматика |
| Конец фразы → текст | 0.2–0.6 с | пауза 0.8 с + декодирование |
| Быстрый скилл | 1–50 мс | локально |
| Первый токен LLM | 0.2–0.8 с | Groq через релей; GigaChat 0.6–1.5 с |
| Синтез первой фразы | 0.1–0.8 с | RHVoice < Piper < Edge |
| **Итого: команда** | **0.5–1.5 с** | до первого звука |
| **Итого: умный ответ** | **1.5–3.5 с** | до первого звука |

Что помогает:

- **Groq основным** — релей на Cloudflare добавляет всего 30–80 мс, зато модель
  отвечает в 3–5 раз быстрее. Если релей недоступен, GigaChat подхватит сам.
- **`reasoning_effort: low`** — у gpt-oss рассуждения стоят секунд и токенов.
- **Edge TTS** — самый красивый голос; если интернет слабый, поставьте первым
  `rhvoice` или `piper` — локально и мгновенно.
- **Ethernet вместо Wi-Fi b/g/n** — на R3700 это часто главный источник задержки.
- **SSD вместо HDD 5400 rpm** — модель Vosk и система грузятся в разы быстрее.
- Не включайте облачное распознавание (`stt.cloud_fallback: groq`) без нужды.
- `brain.max_tokens: 450` и короткий системный промпт уже настроены.

Реальные цифры на вашем железе покажет `python run.py --bench`, а в веб-интерфейсе
есть медиана, p95 и доля ответов быстрее 5 секунд.

## Настройка

Всё лежит в `config.yaml` (создаётся из `config.example.yaml`):

```yaml
assistant:
  wake_words: [привет гуль, слушай гуль]
  persona: |
    Ты — Гуль...            # характер, стиль, правила — любые
  max_history_turns: 8      # сколько помнить в диалоге
  tts_max_chars: 900        # длиннее — обрежется при озвучке

audio:
  input_device: default     # или plughw:1,0
  output_device: default
  barge_in: true            # перебивать словом «стоп»

tts:
  engines: [edge, piper, rhvoice, espeak]
  edge_voice: ru-RU-DmitryNeural
  speed: 1.0

brain:
  order: [gigachat, groq, cloudflare, generic, mock]
  first_token_timeout: 8
  gigachat:
    verify_ssl: false       # у Сбера свой корневой сертификат

network:
  proxy: ""                 # socks5h://127.0.0.1:1080 — только для прямого Groq/Edge

skills:
  weather:
    city: Москва
  music:
    library_dirs: [~/Music]
    radio:
      - name: Европа Плюс
        url: https://ep128.hostingradio.ru:8030/ep128
  mqtt:
    enabled: false
    devices:
      - name: свет на кухне
        topic: home/kitchen/light/set
        on: "ON"
        off: "OFF"

web:
  host: 0.0.0.0
  port: 8787
  token: ""                 # задайте пароль, если открываете порт в сеть
  speak: false              # озвучивать ответы из веб-чата
```

Секреты — только в `.env` (файл в `.gitignore`). Данные (заметки, память,
таймеры, кэш курсов) — в `data/`, тоже не попадают в Git.

## Умения Алисы: сравнение

Подробная таблица — [docs/ALICE_SKILLS.md](docs/ALICE_SKILLS.md).
Коротко:

- ✅ **Есть и работает:** время, погода, будильники, таймеры, напоминания,
  калькулятор, курсы, новости, факты, перевод, заметки, список покупок, память,
  радио и локальная музыка, умный дом по MQTT, свободный разговор, учёба и
  объяснения, шутки и истории, практика английского, свой характер.
- 🟡 **Частично:** музыка без Яндекс.Музыки (радио + своя фонотека), умный дом
  только через MQTT/Home Assistant, новости без персональных подборок,
  будильник «каждый день», но не «по будням».
- ❌ **Невозможно без экосистемы Яндекса:** Яндекс.Музыка по подписке, такси,
  Афиша, Маркет, Yandex Pay, звонки, карты и пробки, мультирум, управление
  Станцией, радионяня, поиск телефона, генерация изображений/видео.

Зато у Гуля есть то, чего у Алисы нет: **ноль подписок и рекламы, любой системный
промпт, долговременная память, свои навыки на Python за 20 строк и полная
прозрачность того, что происходит.**

### Добавить свой навык за 20 строк

```python
from gul.skills.base import Skill, SkillContext, SkillResult

class CoinSkill(Skill):
    name = "coin"
    title = "Монетка"
    priority = 50

    def handle(self, text: str, ctx: SkillContext) -> SkillResult | None:
        if "подбрось монетку" in text:
            import random
            return SkillResult(text=random.choice(["Орёл.", "Решка."]))
        return None
```

Зарегистрируйте его в `gul/skills/registry.py` — и всё.

## Диагностика

| Симптом | Что делать |
|---|---|
| `arecord: ... No such file` | `python run.py --list-devices`, укажите `plughw:1,0` в `audio.input_device` |
| Микрофон есть, но тишина | `python run.py --mic-test 4`; `alsamixer` → F4 (Capture) → включите и поднимите Gain |
| Не понимаю, что сломано | `python run.py --doctor` — проверяет всё по очереди и подсказывает |
| `Модель Vosk не найдена` | `bash scripts/download_models.sh` |
| GigaChat 401 | проверьте `GIGACHAT_CLIENT_ID/SECRET` и `scope: GIGACHAT_API_PERS`; удалите `data/.gigachat_token.json` |
| GigaChat SSL error | уже стоит `verify_ssl: false`; при желании установите сертификат НУЦ Минцифры |
| Groq 403 | это гео-блок РФ: поднимите релей по docs/GROQ.md или пропишите `network.proxy` |
| Нет звука | `sudo apt install alsa-utils ffmpeg mpv`; проверьте `python run.py --say "проверка"` |
| Музыка не играет | `sudo apt install mpv`; проверьте URL радиостанции |
| Служба не слышит микрофон | `sudo usermod -aG audio $USER`, перезайдите/перезагрузитесь |
| Ложные срабатывания «стоп» | `audio.barge_in: false` или уменьшите громкость колонки |
| Высокий CPU | `stt.wake_mode: grammar`, не включайте облачный STT, закройте лишнее |
| Веб не открывается | `web.host: 0.0.0.0`, проверьте firewall и порт 8787 |

## Честные ограничения

- **Полностью офлайновый умный ассистент на D525 невозможен.** Без интернета
  работают команды из списка «быстрые», но не свободный разговор.
- **GigaChat/Edge TTS — чужие бесплатные сервисы.** Условия и лимиты могут
  измениться; поэтому в проекте есть роутер и локальные фолбэки.
- **Качество микрофона важнее кода.** Дешёвый USB-микрофон + колонка рядом дают
  эхо; помогает разнести их, убавить громкость или отключить barge-in.
- **Радиостанции в конфиге — примеры.** Проверьте, что URL живы у вашего
  провайдера, и замените при необходимости.
- **Юридическая сторона:** GigaChat Freemium разрешён для личного
  некоммерческого использования; Edge TTS — бесплатный, но неофициальный
  интерфейс Microsoft. Для коммерческого проекта возьмите платный тариф/локальный TTS.
