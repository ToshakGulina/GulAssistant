# Какие API и аккаунты нужны

Короткий ответ: **из платных/ключевых сервисов нужен только Groq** — ключ у вас
уже есть. Всё остальное либо не требует ключа, либо необязательно.

Но чтобы Groq заработал **из России**, нужен ещё один бесплатный аккаунт —
Cloudflare, для релея (см. [docs/GROQ.md](GROQ.md)). Без него прямой
`api.groq.com` ответит 403, и Гуль уйдёт на резерв.

---

## Обязательное

| Сервис | Что даёт | Ключ | Цена | Из РФ |
|---|---|---|---|---|
| **Groq** | мозг + распознавание речи Whisper | `GROQ_API_KEY` ✅ есть у вас | free: 30 запросов/мин, 1 000/день, 8K токенов/мин | ⚠️ напрямую 403 |
| **Cloudflare (аккаунт)** | релей к Groq, обход гео-блока | `GROQ_RELAY_URL`, `GROQ_RELAY_TOKEN` | free: 100 000 запросов/день, карта не нужна | ✅ обычно |

Этого достаточно, чтобы Гуль работал полностью: умные ответы, погода, новости,
курсы, заметки, таймеры, музыка, распознавание речи.

> ⚠️ **Ключ Groq, отправленный в чат, считайте скомпрометированным.**
> Перевыпустите его на [console.groq.com/keys](https://console.groq.com/keys)
> после проверки. В проекте ключ нужен только в одном из двух мест: в секретах
> Cloudflare Worker (рекомендую) или в `.env` (файл в `.gitignore`, права 600).

---

## Настоятельно рекомендую

| Сервис | Что даёт | Ключ | Цена | Из РФ |
|---|---|---|---|---|
| **GigaChat (Сбер)** | второй мозг, работает без VPN | `GIGACHAT_CLIENT_ID`, `GIGACHAT_CLIENT_SECRET` | 365 млн токенов на 12 мес. физлицу | ✅ |

Зачем, если Groq быстрее: Cloudflare в РФ иногда недоступен у отдельных
провайдеров, а Groq может упереться в дневной лимит. GigaChat — страховка,
которая держит ассистента живым без VPN вообще. Регистрация физлица бесплатна:
[developers.sber.ru](https://developers.sber.ru/portal/products/gigachat-api).

---

## Необязательное

| Сервис | Что даёт | Ключ | Цена | Из РФ |
|---|---|---|---|---|
| **Cloudflare Workers AI** | третий мозг (gpt-oss-120b, Qwen) | `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` | 10 000 нейронов/день | ✅ |
| **MQTT-брокер** (Mosquitto) | умный дом: «включи свет» | локальный, без облака | бесплатно | ✅ |
| **Home Assistant** | если уже есть — интеграция через MQTT | свой токен | бесплатно | ✅ |
| **Прокси/VPN** | альтернатива релею для Groq и Edge TTS | `network.proxy` | зависит от провайдера | — |

---

## Ключи не нужны вообще

| Что | Почему |
|---|---|
| **Погода** | Open-Meteo: бесплатно, без регистрации, без ключа |
| **Курсы валют** | официальный API ЦБ РФ |
| **Новости** | RSS-ленты (Лента, Интерфакс) |
| **Факты и справки** | Википедия REST API |
| **Синтез речи** | Edge TTS (Microsoft, без ключа) + локальные Piper/RHVoice/espeak |
| **Распознавание речи** | Vosk работает полностью офлайн, модель скачивается один раз |
| **Радио и музыка** | прямые ICY-потоки и локальные файлы через mpv |
| **Заметки, память, таймеры** | локальные JSON-файлы на диске |

## Что делать прямо сейчас

1. **Перевыпустите ключ Groq** (он был в переписке).
2. **Создайте релей** по [docs/GROQ.md](GROQ.md) — 5 минут, бесплатно.
   Положите новый ключ в секрет `GROQ_API_KEY` на стороне Worker.
3. На машине с Гулём:

```bash
bash scripts/quickstart.sh
# URL релея:   https://gul-groq-relay.xxx.workers.dev/openai/v1
# Токен:       ваш RELAY_TOKEN
# Ключ Groq:   Enter (он живёт в Worker, на неттопе не нужен)
# GigaChat:    Enter или ключи
```

4. Проверка:

```bash
python run.py --brain groq     # должен ответить за <1 с
python run.py --doctor
```

## Быстрая проверка ключа вручную

Если сомневаетесь, жив ли ключ, — одна команда (не печатает ключ в истории,
если начать строку с пробела):

```bash
curl -s -H "Authorization: Bearer ВАШ_КЛЮЧ" https://api.groq.com/openai/v1/models | head -c 200
```

- список моделей → ключ жив;
- `401` → ключ неверный или отозван;
- `403` → ключ в порядке, но IP российский: нужен релей или VPN;
- таймаут → сеть/Cloudflare.

`python run.py --brain groq` делает то же, но ещё и объясняет причину словами.

## Сколько это стоит в итоге

| Статья | Стоимость |
|---|---|
| Groq free | 0 ₽ |
| Cloudflare Workers free | 0 ₽ |
| GigaChat Freemium | 0 ₽ |
| Open-Meteo, ЦБ, RSS, Википедия | 0 ₽ |
| Edge TTS, Vosk | 0 ₽ |
| **Итого** | **0 ₽**, карта не требуется нигде |

Единственное, что реально ограничивает, — дневные лимиты Groq (1 000 запросов,
200 000 токенов). Для домашнего голосового ассистента этого хватает с большим
запасом; при упоре в лимит Гуль сам уходит на GigaChat и возвращается обратно.
