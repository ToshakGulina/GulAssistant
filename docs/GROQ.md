# Groq как основной мозг: настройка за 10 минут

Groq — самый быстрый бесплатный LLM-сервис: железо LPU выдаёт ~1000 токенов/с
на `gpt-oss-20b`, первый токен приходит за 200–600 мс. Для голосового ассистента
это лучший вариант: ответ начинается почти сразу.

Проблема одна: **из России `api.groq.com` отвечает 403** (гео-блок по IP).
Есть три способа это обойти, и все три уже поддержаны в коде.

---

## Три режима подключения

| Режим | Что нужно | VPN | Ключ Groq на неттопе | Задержка |
|---|---|---|---|---|
| **Релей на Cloudflare** (рекомендую) | аккаунт Cloudflare, 5 минут | нет | **нет** | +30–80 мс |
| Прямой через прокси/VPN | работающий прокси (Happ и т.п.) | да | да | +50–300 мс |
| Прямой без прокси | — | — | да | из РФ не работает (403) |

Релей — это маленький Worker на Cloudflare, который принимает запрос из РФ и
уходит в Groq уже с зарубежного edge. Ключ Groq хранится в секретах Worker,
поэтому даже если неттоп украдут — ключ не утечёт. Бесплатный тариф Workers:
100 000 запросов в день, карта не нужна.

Инструкция по релею: [`relay/README.md`](../relay/README.md).

---

## Шаг 1. Получите ключ Groq

1. [console.groq.com/keys](https://console.groq.com/keys) → зарегистрируйтесь
   (карта не нужна).
2. **Create API Key** → скопируйте `gsk_...`.

Ключ понадобится только внутри Worker, если идёте через релей.

---

## Шаг 2. Поднимите релей

Коротко (подробности — в `relay/README.md`):

1. dash.cloudflare.com → **Workers & Pages → Create → Worker**;
2. вставьте `relay/groq-relay.js`, нажмите **Deploy**;
3. **Settings → Variables and Secrets**:
   - `GROQ_API_KEY` = `gsk_...` (Secret),
   - `RELAY_TOKEN` = длинный пароль, например `openssl rand -hex 24` (Secret);
4. скопируйте URL вида `https://gul-groq-relay.xxx.workers.dev`.

Проверка:

```bash
curl https://gul-groq-relay.xxx.workers.dev/health
curl -H "Authorization: Bearer ВАШ_RELAY_TOKEN" \
     https://gul-groq-relay.xxx.workers.dev/openai/v1/models
```

Второй запрос должен вернуть список моделей.

---

## Шаг 3. Пропишите в Гуле

```bash
nano .env
```

```dotenv
GROQ_RELAY_URL=https://gul-groq-relay.xxx.workers.dev/openai/v1
GROQ_RELAY_TOKEN=ваш_длинный_пароль
```

Всё. `config.example.yaml` уже содержит `relay_url: ${GROQ_RELAY_URL}`,
`relay_token: ${GROQ_RELAY_TOKEN}` и ставит Groq первым в `brain.order`.
Менять YAML не нужно.

Если релея нет, но есть VPN/прокси:

```dotenv
GROQ_API_KEY=gsk_...
```

```yaml
network:
  proxy: socks5h://127.0.0.1:1080    # или http://127.0.0.1:8118
```

`PySocks` уже в `requirements.txt`, так что `socks5h://` работает из коробки.

---

## Шаг 4. Проверьте

```bash
.venv/bin/python run.py --brain groq
```

Ожидаемо:

```
Мозги Гуля
Порядок: groq → gigachat → cloudflare → generic → mock
Groq: через релей https://gul-groq-relay.xxx.workers.dev/openai/v1
Модель Groq: openai/gpt-oss-20b

[OK] Groq (через свой релей) · режим: relay · openai/gpt-oss-20b:
     первый токен 412 мс, всего 780 мс
     «Привет!»
```

Затем:

```bash
.venv/bin/python run.py --doctor
.venv/bin/python run.py --bench
```

В веб-интерфейсе в блоке «Мозг» Groq будет первым, с пометкой режима.

## Что настроено для скорости

| Параметр | Значение | Зачем |
|---|---|---|
| `model` | `openai/gpt-oss-20b` | ~1000 ток/с, для голоса достаточно умён |
| `reasoning_effort` | `low` | thinking съедает секунды и лимит токенов |
| `include_reasoning` | `false` | рассуждения не нужны в ответе |
| `token_param` | `max_completion_tokens` | Groq считает reasoning в этом лимите |
| `brain.max_tokens` | `450` | короче ответ — быстрее первая фраза |

Хотите умнее — поставьте `openai/gpt-oss-120b` (вдвое медленнее, но заметно
сильнее). Хотите ещё быстрее — `max_tokens: 300` и `max_history_turns: 6`.

## Лимиты Groq (free, октябрь 2026)

| Модель | Запросов/мин | Запросов/день | Токенов/мин | Токенов/день |
|---|---|---|---|---|
| `openai/gpt-oss-20b` | 30 | 1 000 | 8 000 | 200 000 |
| `openai/gpt-oss-120b` | 30 | 1 000 | 8 000 | 200 000 |

Для голосового ассистента это 8–15 коротких ответов в минуту. Узкое место —
8 000 токенов в минуту: в них входят системный промпт, история диалога и ответ.
Если упираетесь — сократите историю и `max_tokens`.

Гуль не падает от лимитов: на `429` он ставит Groq на паузу **45 секунд**,
молча отвечает через GigaChat и возвращается к Groq, когда лимит отпустит.
На `401/403` пауза 300 секунд — бессмысленно долбить закрытый доступ.

## Если что-то не работает

| Симптом | Причина | Решение |
|---|---|---|
| `403` от релея | неверный `RELAY_TOKEN` | сверьте `.env` и секрет Worker |
| `401` от Groq | ключ неверный/отозван | перевыпустите ключ |
| `403` от Groq | ключ в Worker не тот, или запрос всё же из РФ | проверьте `GROQ_API_KEY` в Worker; `/health` должен показать `key_configured: true` |
| `429` | лимит | подождите; уменьшите историю и `max_tokens` |
| `502 upstream_unreachable` | Worker не достучался до Groq | повторите позже, проверьте статус Groq |
| `404 not_found` | URL релея без `/openai/v1` | добавьте `/openai/v1` в конце |
| Релей недоступен у провайдера | блокировка Cloudflare | проверьте с мобильного интернета; запасной путь — VPN + прямой Groq |
| Пустые ответы | reasoning съел весь лимит | `reasoning_effort: low` уже стоит; поднимите `max_tokens` до 600 |
| Медленно (>2 с до токена) | релей далеко / прокси медленный | попробуйте другой прокси; проверьте `--bench` |

Полная диагностика: `python run.py --brain groq` — она печатает не только ошибку,
но и что с ней делать.

## Тот же ключ — для распознавания речи

Groq Whisper работает с тем же ключом и через тот же релей. В
`config.example.yaml` уже стоит `stt.cloud_fallback: groq`: если Vosk не разобрал
ни слова, Гуль отправит короткий WAV в Whisper и не скажет «Не расслышала».
Стоит это 0.5–1.5 с и срабатывает только при провале локального распознавания —
на обычную задержку не влияет.

Отключить: `stt.cloud_fallback: none`.

## Какие ещё API нужны

Только Groq и аккаунт Cloudflare для релея. GigaChat — желательный резерв,
всё остальное (погода, курсы, новости, Википедия, TTS, Vosk) ключей не требует.
Полная таблица: [API_KEYS.md](API_KEYS.md).

## Честные оговорки

- **Релей — это ваш личный мост, а не публичный прокси.** Он принимает только
  `chat/completions` и `models`, требует токен и работает с вашим ключом.
  Не раздавайте доступ и не делайте из него сервис: массовая раздача чужих API
  нарушает условия Cloudflare.
- **Cloudflare может быть недоступен у отдельного провайдера в РФ.** Тогда
  остаются VPN + прямой Groq или GigaChat. Гуль переключится сам.
- **Бесплатные тарифы меняются.** Лимиты и модели проверяйте в кабинете Groq;
  в проекте есть роутер и фолбэки именно поэтому.
- **Данные:** в Groq уходит только текст вопроса и истории, аудио остаётся
  на устройстве. Для приватных разговоров есть GigaChat (РФ) и демо-режим.
