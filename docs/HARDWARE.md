# Железо: Acer Aspire R3700 и Debian

## Что внутри

| Компонент | Значение | Комментарий |
|---|---|---|
| CPU | Intel Atom **D525**, 2 ядра / 4 потока, 1.8 ГГц | Pineview, 45 нм, 13 Вт |
| Инструкции | SSE2, SSE3, **SSSE3** | **нет SSE4.1/4.2, AVX, AVX2** |
| Чипсет | Intel NM10 | |
| RAM | 2 слота SO-DIMM DDR3-800, **максимум 4 ГБ** | 2×2 ГБ — потолок |
| GPU | NVIDIA ION 2 | Для ассистента не используется |
| Диск | SATA 2.5", 250/320/500 ГБ HDD 5400 rpm | SSD — лучший апгрейд |
| Сеть | Gigabit Ethernet, Wi-Fi 802.11 b/g/n | Для стабильности — кабель |
| Звук | Встроенный HDA + USB-микрофон/колонка | Настраивается через ALSA |
| Питание | Адаптер 65 Вт | Реальное потребление ~20–35 Вт |

Ограничение по инструкциям — главное. Оно означает:

- современные `onnxruntime`, `ctranslate2`, часть сборок `torch` могут падать
  с `Illegal instruction`;
- локальная LLM на 1–3 токена/с — не вариант для голосового диалога;
- Vosk small, RHVoice, espeak, ffmpeg, mpv работают нормально;
- Piper/onnxruntime нужно проверять именно на вашей сборке (поэтому он
  необязателен и стоит после Edge TTS).

Вывод: **D525 — отличный тонкий клиент, но не «мозг».** Так же устроена и
Яндекс Станция: она тоже отправляет запрос в облако.

## Апгрейды, которые реально чувствуются

1. **SSD на 120–240 ГБ** вместо HDD 5400 rpm. Система и модель Vosk грузятся
   в 3–5 раз быстрее, нет шума и вибрации. Формат 2.5" SATA.
2. **Ethernet-кабель** вместо Wi-Fi b/g/n. На слабом канале именно сеть даёт
   +0.5–2 секунды к ответу.
3. **2×2 ГБ DDR3-800 SO-DIMM** — если сейчас 3 ГБ или меньше. Больше 4 ГБ
   чипсет не увидит.
4. **Нормальный USB-микрофон** с аппаратным шумоподавлением или петличка.
   Дешёвый «микрофон из набора» — главный источник ошибок распознавания.
5. **Колонка подальше от микрофона** — меньше эха и ложных «стоп».

Процессор и GPU не апгрейдятся (BGA). Если захочется локальную LLM — это уже
другая машина (см. «Апгрейд пути» в конце).

## Установка Debian с нуля

### 1. Загрузочная флешка

Скачайте **Debian 12/13 netinst amd64** с debian.org и запишите на флешку
(Rufus в Windows, balenaEtcher, или `dd` в Linux). Для R3700 хватит 2–4 ГБ.

### 2. BIOS и загрузка

- Вставьте флешку, включите неттоп.
- Нажмите **F12** (Boot Menu) или **Del/F2** (BIOS), выберите USB.
- Secure Boot можно оставить включённым — Debian его поддерживает.
- Если экран не виден на HDMI при загрузке, попробуйте VGA-кабель или
  режим совместимости в BIOS.

### 3. Установщик

Рекомендуемые ответы:

| Шаг | Выбор |
|---|---|
| Язык | Русский (или English — не принципиально) |
| Hostname | `gul` |
| Пользователь | `gul` (не root), пароль запомните |
| Разметка | «Весь диск» + LVM или обычная ext4 |
| Desktop | **нет** (снимите все галочки) |
| SSH server | **да** |
| Standard utilities | **да** |
| Firmware | если предложит — установите |

Графический стол на 4 ГБ не нужен: он съест 300–500 МБ и добавит фоновые
процессы. Управлять будем по SSH.

### 4. Первый вход

```bash
ssh gul@IP-НЕТТОПА
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y sudo curl ca-certificates git
```

Желательно закрепить IP за неттопом в DHCP роутера — тогда адрес веб-интерфейса
не будет меняться.

Если нужен Wi-Fi (не рекомендую): установите firmware для вашей карты
(`firmware-iwlwifi`, `firmware-atheros` и т.п. из non-free) и настройте
`wpa_supplicant`/NetworkManager. Кабель надёжнее.

### 5. Звук

```bash
alsamixer
```

- **F6** — выбрать звуковую карту (встроенную или USB-микрофон).
- **F4** — режим Capture, **пробел** — снять mute, стрелками — Gain.
- **F3** — Playback, проверьте громкость.

Проверка записи и воспроизведения:

```bash
arecord -l                 # список микрофонов
aplay -l                   # список колонок
arecord -D plughw:1,0 -f S16_LE -r 16000 -c 1 -d 5 /tmp/test.wav
aplay /tmp/test.wav
```

Если слышно тихо/шумно — поднимите Capture и уменьшите Boost, подвиньте
микрофон. В `config.yaml` укажите:

```yaml
audio:
  input_device: plughw:1,0    # номер карты из arecord -l
  output_device: plughw:0,0
  vad_threshold: 0            # 0 = авто; если ловит шум, поставьте 250–400
```

Пользователь должен быть в группе `audio`:

```bash
sudo usermod -aG audio $USER
```

После этого перезайдите по SSH (или перезагрузитесь).

### 6. Установка Гуля

```bash
git clone https://github.com/ToshakGulina/GulAssistant.git
cd GulAssistant
bash scripts/setup_debian.sh
nano .env            # ключи GigaChat
.venv/bin/python run.py --check
.venv/bin/python run.py --bench
sudo systemctl start gul
journalctl -u gul -f
```

## Ожидаемая нагрузка

| Процесс | RAM | CPU |
|---|---|---|
| Debian без графики | 250–350 МБ | 1–3% |
| Python + скиллы + веб | 120–180 МБ | 1–5% |
| Vosk (модель + распознавание) | 200–250 МБ | 5–25% при речи |
| mpv (когда играет) | 20–40 МБ | 2–10% |
| TTS (RHVoice/espeak) | 30–80 МБ | кратковременно 30–80% |

Итого в покое — около **0.7–0.9 ГБ** и почти нулевой CPU. На 4 ГБ остаётся
запас для кэша и обновлений.

Температура: D525 греется умеренно, но у R3700 маленький корпус. Почистите
радиатор от пыли, не ставьте неттоп на мягкую поверхность, оставьте вентиляцию.
Для круглосуточной работы желателен качественный блок питания; идеально — ИБП.

Потребление: ~20–35 Вт в реальности. За год круглосуточной работы — порядка
200–300 кВт·ч; при московском тарифе это несколько тысяч рублей. Можно
настроить автозасыпание, но тогда ассистент не будет слушать.

## Проверка задержек именно на вашем железе

```bash
.venv/bin/python run.py --bench
```

Скрипт покажет:

- доступные TTS-движки и время синтеза фразы (первый запуск — с прогревом);
- время до первого токена каждого настроенного LLM;
- загрузку модели Vosk и скорость разбора 2 секунд тишины;
- напомнит, как складывается итоговая задержка.

Затем откройте веб-интерфейс: там медиана, p95 и доля ответов быстрее 5 секунд.
Если медиана выше 4 секунд:

1. Проверьте интернет по кабелю (`speedtest-cli`).
2. Поставьте `rhvoice` первым в `tts.engines` (мгновенно, но голос проще).
3. Убедитесь, что GigaChat — первый в `brain.order`.
4. Уменьшите `brain.max_tokens` до 300.
5. Отключите `stt.cloud_fallback`, если он включён.

## Апгрейд пути

- **Сейчас:** R3700 как тонкий клиент + бесплатное облако. 0 ₽.
- **Через год:** мини-ПК на Intel N100 / 16 ГБ / SSD за ~15–20 тыс. ₽. На нём
  уже можно держать Qwen 3–4B в llama.cpp и получить локальные умные ответы
  за 1–3 секунды. Архитектура Гуля не изменится: достаточно добавить
  OpenAI-совместимый провайдер `generic` с `http://127.0.0.1:8080/v1`.
- **Альтернатива:** Raspberry Pi 4/5 (8 ГБ) — тот же код, меньше энергопотребление,
  но AAC/MP3-радио и mpv могут потребовать настройки.

## Частые проблемы R3700

| Проблема | Решение |
|---|---|
| Не грузится с USB | F12 при старте; в BIOS включите USB Boot / Legacy |
| Нет изображения на HDMI | Попробуйте VGA; ION иногда капризен к кабелю/монитору |
| Wi-Fi не находится | Нужен firmware из non-free; проще кабель |
| Микрофон не виден | `arecord -l`; USB-микрофон может быть card 1 |
| Треск/эхо | Убавьте громкость колонки, разнесите микрофон, `barge_in: false` |
| Шумит HDD | SSD; также проверьте крепление |
| Служба не стартует после обновления | `journalctl -u gul -n 100`; обычно не хватает пакета или прав на звук |
| Веб открывается только локально | `web.host: 0.0.0.0`, firewall, правильный IP |
