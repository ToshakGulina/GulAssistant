# Умения Алисы и Гуля: честное сравнение

Каталог Алисы в 2026 году — это десятки навыков и целая экосистема Яндекса
(Музыка, Такси, Афиша, Маркет, Браузер, умные устройства). Ниже — что из этого
реализовано в Гуле, что реализовано частично и что принципиально невозможно
без подписки и экосистемы.

Обозначения: ✅ — работает, 🟡 — частично/иначе, ❌ — нет и не планируется
без сторонних сервисов.

## Итог

**Что Гуль делает не хуже Алисы:** время, погода, будильники, таймеры,
напоминания, курсы, калькулятор, новости, факты, перевод, заметки, список
покупок, память, радио/музыка, свободный диалог, учёба, шутки, английский.

**Что Гуль делает лучше:** бесплатно и без подписки; нет рекламы и цензурных
ограничений модели; можно задать любой характер; память о пользователе; свои
навыки; прозрачность и открытый код; базовые команды работают без интернета
и без задержки.

**Что Алиса делает лучше:** вся экосистема Яндекса — Музыка, Такси, Афиша,
Маркет, Станции, мультирум, звонки, карты, покупки, генерация картинок,
радионяня и т.д. Это невозможно воспроизвести без партнёрства и подписки.

Если нужен паритет по конкретному сервису — почти всегда есть путь: MQTT для
умного дома, RSS для новостей, локальные файлы для аудиокниг, LLM для игр.
Так Гуль и остаётся бесплатным и независимым.
