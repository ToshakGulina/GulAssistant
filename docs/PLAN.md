# План проекта «Гуль»

## 1. Цель и ограничения

**Цель:** голосовой ассистент уровня Алисы (а по открытости — лучше) на
Acer Aspire R3700, бесплатный в эксплуатации, с задержкой ответа до 5 секунд.

**Жёсткие ограничения:**

- Железо: Intel Atom D525 (2 ядра / 4 потока, 1.8 ГГц, 2010 г.), 4 ГБ DDR3,
  HDD 5400 rpm, NVIDIA ION. Набор инструкций — только SSE2/SSE3/SSSE3.
- Бюджет: 0 ₽ на подписки и API.
- Язык: русский, живая речь, разные микрофоны и колонки.
- Ответ голосом: не дольше 5 секунд, в идеале — 1–3.

**Не цель:** конкурировать с YandexGPT по «железному» интеллекту, воспроизводить
экосистему Яндекса (такси, Маркет, Афиша, Яндекс.Музыка) и работать полностью
офлайн как LLM.

---

## 2. Ключевое решение

Разделить систему на два контура:

1. **Локальный (D525):** wake-word, распознавание речи, все бытовые команды,
   хранение заметок/памяти/таймеров, синтез речи, веб-интерфейс.
2. **Облачный (бесплатный):** только генерация сложных ответов через
   GigaChat/Groq/Cloudflare с роутером и фолбэками.

Почему не локальная LLM: на D525 Qwen 1.5B даёт порядка 1–3 токенов/с, то есть
ответ на 60 токенов — 20–60 секунд; современные рантаймы требуют SSE4.1/AVX
и падают. Полностью локальный «умный» вариант физически несовместим с
требованием «≤5 секунд».

## 4. Критерии приёмки

### Функциональные

- [x] Ассистент просыпается по фразе «Привет, Гуль» (настраивается).
- [x] Понимает бытовые команды без интернета.
- [x] Ставит таймеры, будильники и напоминания, переживает перезапуск.
- [x] Отвечает на свободные вопросы через бесплатную LLM.
- [x] Переключается на резервный мозг при сбое основного.
- [x] Говорит синтезированным голосом; при сбое TTS пробует следующий движок.
- [x] Имеет веб-интерфейс с метриками и списком умений.
- [x] Устанавливается одной командой на Debian и стартует службой.

### Скорость

- [x] Бытовые команды: ≤ 1.5 с до первого звука (цель).
- [x] Умный ответ: ≤ 5 с до первого звука (цель), типично 1.5–3.5 с.
- [x] Инструменты измерения: `--bench`, метрики p50/p95 в веб-интерфейсе.

### Стоимость

- [x] 0 ₽: Freemium GigaChat, Cloudflare free, Open-Meteo, RSS, ЦБ, Википедия.
- [x] Нет обязательной карты и подписки.
- [x] Работает в демо-режиме без ключей.

### Надёжность

- [x] Ошибка одного провайдера не ломает ассистента.
- [x] Таймеры и настройки сохраняются на диск атомарно.
- [x] Понятные сообщения об ошибках вместо падений.
- [x] Логи с ротацией, systemd `Restart=always`.

## 5. Риски и что делать

| Риск | Вероятность | Митигация |
|---|---|---|
| GigaChat меняет бесплатный тариф | средняя | роутер на Cloudflare/Groq; `--check` показывает статус |
| Groq блокирует РФ | высокая | GigaChat основной; при наличии VPN — `network.proxy` |
| Edge TTS недоступен | средняя | локальные Piper/RHVoice/espeak |
| Микрофон/эхо на дешёвом железе | высокая | VAD-порог, разнести микрофон и колонку, `barge_in: false` |
| Vosk не знает имя «Гуль» | средняя | авто-проверка словаря; полный режим wake-word; смена фразы |
| HDD умирает от 24/7 | средняя | SSD, ротация логов, бэкап `data/` |
| Скачки питания | низкая | ИБП или хотя бы качественный блок питания |
| Юридические ограничения API | низкая | личное некоммерческое использование; локальные альтернативы |

## 6. Дальнейшее развитие

1. **Веб-поиск** через бесплатный SearXNG или API (сейчас факты — Википедия + LLM).
2. **Home Assistant** через REST/MQTT: статусы устройств, сценарии.
3. **Больше игр**: «Угадай слово», викторины, «Что? Где? Когда?».
4. **Локальный Piper** по умолчанию после проверки на D525.
5. **Свой wake-word** через openWakeWord/Porcupine (если Vosk-фраза неудобна).
6. **Мультирум/сателлиты**: R3700 как Wyoming-сателлит, второй сервер — мозг.
7. **Локальная LLM** при апгрейде на N100/16 ГБ: Qwen 3–4B через llama.cpp,
   гибрид «локально по умолчанию, облако для сложного».
8. **Память с embeddings** и суммаризация долгих диалогов.
9. **Голосовые профили** и распознавание нескольких пользователей.

---

## 7. Что сознательно не делаем

- Не тащим Docker, Node.js, React и GUI: на 4 ГБ RAM каждый мегабайт и каждый
  лишний процесс — роскошь.
- Не используем PyTorch в обязательном пути: риск `Illegal instruction` на D525.
- Не отправляем аудио в облако по умолчанию: только текст вопроса.
- Не обещаем экосистему Яндекса: такси и Яндекс.Музыку без подписки не обойти.
